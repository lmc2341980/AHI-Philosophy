# AHI-Workspace and Case Evolution Principle

Status: APPROVED WORKING ARTIFACT
Priority: IMPORTANT
Version: v1.0.0

AHI work must be traceable across space and time.

Each session contributes to two synchronized layers: Public/Shared Work and Personal/Private Work.

Preserve Case → Parent → Child → Artifact → Evidence → Decision → Validation → Evolution.

When a task is URGENT + IMPORTANT, select the relevant case first. When no higher-priority case requires immediate work, proceed from the lowest unfinished branch upward to build detail.

AHI-WS and AHI-L provide continuity and organization. They do not replace human authority or the constitutional framework.
